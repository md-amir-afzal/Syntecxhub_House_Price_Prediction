# Internship Submission Checklist

- [x] Housing dataset loaded
- [x] Data cleaning performed
- [x] Features selected
- [x] Train/test split
- [x] Linear Regression trained
- [x] RMSE calculated
- [x] R² calculated
- [x] Coefficients printed
- [x] Model persistence implemented
- [x] Example prediction implemented
- [x] Streamlit demo included
- [x] Automated test included
- [x] README documentation included

## Before submitting
1. Run `python src/train.py`
2. Run `pytest`
3. Run `streamlit run app.py`
4. Review `reports/model_results.json`
5. Push the complete repository to GitHub.
6. Submit the GitHub link through the official internship submission form.
